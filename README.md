# CE_Car_Dif23
> Este es un proyecto simple que busca definir un objeto que abstraiga las caracteristicas esenciales del grupo sobre los puntos de una curva eliptica con caracteristica distinta de 2 y 3.
>
> Algunas caracteristicas que se tienen son
- Instancia del *lugar geometrico* de una curva eliptica dados parametros (*coeficiente del termino lineal de x, termino constante y caracteristica del campo*)
- Suma de puntos en *coordenadas afines*
- Duplicacion de puntos en *coordeadas afines*
- Generacion de orbitas de puntos en *coordenadas afines*
